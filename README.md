# Лабораторная работа № 3

## Асинхронный JavaScript и REST API

### Тема проекта

Доска публикаций.

### Как запустить приложение

1. Создать папку для проекта.
2. Поместить в неё файлы:
   - index.html
   - style.css
   - app.js
   - README.md
3. Открыть файл index.html в браузере.
4. Для работы приложения необходимо подключение к интернету.

Сервер и установка дополнительных библиотек не требуются.

### Реализованные функции

1. Загрузка пяти публикаций с помощью GET-запроса.
2. Использование fetch и async/await.
3. Проверка HTTP-ответа через response.ok.
4. Преобразование ответа сервера в JSON.
5. Отображение публикаций через DOM.
6. Создание публикации через POST-запрос.
7. Проверка заголовка и текста на пустые значения.
8. Удаление пробелов по краям введённых значений с помощью trim().
9. Отправка данных в формате JSON с помощью JSON.stringify().
10. Получение ID созданной публикации из ответа сервера.
11. Отображение сообщений об успешной отправке и ошибках.
12. Блокировка кнопок на время выполнения запросов.
13. Обработка ошибок через try/catch/finally.

### Используемый API

Для работы используется JSONPlaceholder:

GET:
https://jsonplaceholder.typicode.com/posts?_limit=5

POST:
https://jsonplaceholder.typicode.com/posts

### Результаты проверки

1. Нажать кнопку «Загрузить публикации».
   Должны появиться пять публикаций с заголовками и текстом.

2. Попробовать отправить пустую форму.
   Должно появиться сообщение об ошибке.

3. Ввести только пробелы в поля.
   Должно появиться сообщение об ошибке, запрос не должен отправляться.

4. Ввести корректный заголовок и текст.
   Должно появиться сообщение об успешном создании публикации с её ID.

5. Временно заменить GET_URL на адрес:
   https://jsonplaceholder.typicode.com/postz

   Должно появиться сообщение об ошибке. После проверки необходимо вернуть правильный адрес.

### Особенности

JSONPlaceholder имитирует создание публикаций.
Новые записи не сохраняются на сервере постоянно.

Данные отображаются на странице без её перезагрузки.
